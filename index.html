Chrome Extension · v0.5.1

Scroll Capture

Record your websites and automate scrolling and mouse actions for your portfolio screen captures. This is a Manifest V3 Chrome extension — it runs inside the browser as an installed extension, not as a web app.

How to install & use

  • Open chrome://extensions in Chrome
  • Enable Developer mode (top-right toggle)
  • Click Load unpacked and select this project folder
  • Pin the Scroll Capture extension to your toolbar
  • Navigate to a website and click the extension icon to start recording
